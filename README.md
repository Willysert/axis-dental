# Axis Dental Studio

Sitio web de Axis Dental Studio · Torre Agalta, Blvd. Morazán, piso 10, local 1024 · Tegucigalpa, Honduras.

- `index.html`: la página completa (HTML, CSS y JavaScript en un solo archivo).
- `img/`: fotos y logo (`axis-logo.svg`).
- `video/`: videos de la clínica.

El número de WhatsApp se cambia en `index.html`, en la línea `var WHATSAPP = "50487926121";`.
